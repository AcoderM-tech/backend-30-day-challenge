# Backend 30 kunlik challenge

Noldan Python backend dasturchi bo'lish yo'lida 30 kunlik o'rganish challenge'i. Har kuni o'rganilgan mavzu va yozilgan kod shu repoda saqlanadi.

## Maqsad

30 ish kuni (yakshanba dam) davomida Python backend uchun zarur poydevorni qurish va portfolio uchun 3-4 ta real loyiha qilish.

## Reja

| Hafta | Kunlar | Mavzular |
|---|---|---|
| 1 | 1-7 | Python asoslari, OOP, Git, Linux, mini loyiha (CLI todo) |
| 2 | 8-14 | HTTP/REST, SQL, PostgreSQL, Redis, FastAPI, SQLAlchemy |
| 3 | 15-21 | Django, DRF, JWT, testlash (pytest), xavfsizlik, buyurtma/to'lov API |
| 4 | 22-30 | Celery, Docker, Nginx, CI/CD, deploy, arxitektura, yakuniy loyiha |
